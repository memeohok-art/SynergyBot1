Synergy — creator comment assistant

Synergy is a small tool for YouTube creators. A creator asks to be added, proves the channel is theirs, and Synergy then leaves one short, relevant comment on each new video they publish.

What Synergy does

  • Reads a channel's public video list (titles, durations, publish dates) using the YouTube Data API.
  • Posts one comment per video, written for that specific video, spaced at least a minute apart.
  • Never comments on the same video twice, and never exceeds a fixed small daily limit per channel.
  • Lets creators apply and withdraw at any time by asking the operator.

What Synergy does not do

  • It does not read private data, messages, or analytics.
  • It does not post on behalf of anyone but the channel that authorised it.
  • It does not sell, share, or publish any data to third parties.

Verifying channel ownership

A creator is only added after placing a one-time code in their own channel description, which only someone with channel access can do. The code is checked once and can then be removed.

Applying

Applications are handled in the Synergy Discord server. Operators review each request manually; nothing is added automatically.

Privacy

How Synergy handles Google user data — what it reads, stores and how to have it deleted — is set out in the privacy policy. The same link appears on the Google authorisation screen.
