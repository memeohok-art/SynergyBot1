Privacy Policy

Synergy · Last updated

This policy explains what data Synergy (“the tool”, “we”) collects when a YouTube creator authorises it, why it is needed, and how to have it removed.

1. What Google user data we access

  • Public channel and video metadata — a channel's public video list, titles, durations and publish dates. Read via the YouTube Data API using the youtube.force-ssl scope.
  • The ability to post a comment — the same scope allows the tool to create a comment on a video the authorised channel can comment on.

We do not access private messages, private account details, analytics, subscriber lists, revenue data, or any other Google data.

2. How we use it

  • To write one short comment on a newly published video of a channel that asked to be included.
  • To avoid commenting twice on the same video.
  • To keep within a small fixed daily limit so no channel is flooded.

Data is used only for these purposes. It is never used for advertising, profiling, or model training.

3. What we store

  • An OAuth refresh token, held in an encrypted secret store, used solely to post comments.
  • A record of which video IDs have already been commented on, with the comment text and timestamp.
  • The channel handle and an application timestamp for creators who asked to be added.

Stored records live in a private repository and a private server. They are not publicly readable.

4. Sharing

We do not sell, rent, trade, or share Google user data with third parties. No data is shared with advertising networks or data brokers. Comments are posted publicly on YouTube, as that is the tool's purpose.

5. Retention and deletion

  • Comment records are kept so the tool never posts twice on the same video.
  • You can request removal at any time by emailing the address below. We will delete your stored records and revoke the token within 7 days.
  • You can revoke access yourself at myaccount.google.com/permissions, which immediately stops all access.
  • Comments already posted can be deleted by the channel owner or the tool operator on request.

6. Security

Tokens are held in an access-controlled secret store, never in source code or public files. Access is limited to the operator of the tool. Transport is HTTPS only.

7. Children

The tool is not directed at children under 13 and no such data is knowingly collected.

8. Changes

If this policy changes materially, the “last updated” date above changes and authorised creators are notified through the Synergy Discord server.

9. Contact

Questions or deletion requests: synergy@example.com

This policy is linked from the Synergy home page and from the Google authorisation screen, as Google requires.
